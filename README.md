Bateria no Louvor

Bateria no Louvor é um curso prático para bateristas que desejam tocar com excelência na igreja. Do básico ao avançado, você aprende ritmo, coordenação, levadas e musicalidade aplicadas ao louvor, com método simples, didático e focado no ministério.
